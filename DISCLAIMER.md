**Purpose**  
This project is a **demonstration of statistical survival analysis** in R and is intended solely for **educational and portfolio purposes**. It is not a formal clinical study.

**Data Source**  
The analysis uses the `colon` dataset from the R `survival` package, which originates from a publicly available clinical trial conducted in the 1980s.
The author did not collect the original data. This project analyses the existing patient-level trial dataset distributed with the R survival package.

**Clinical Use**  
The findings presented here are **not intended for clinical decision‑making, diagnosis, or treatment**. No conclusions drawn from this analysis should be used to guide medical practice or patient care.
